Geliştirirken test anahtarlarını kullanın (sunucuda `cp_sk_test_…`, tarayıcıda `cp_pk_test_…`). Test oturumları (`cs_test_…`) hiçbir zaman gerçek para hareketi yaratmaz ve canlı verilerden ayrı tutulur. Panelde **Ayarlar → Gelişmiş → Headless ve API** sayfasının üstünden **Test** ile **Canlı** arasında geçiş yaparsınız; her modun kendi anahtarları, izinli adresleri ve dönüş imza sırrı vardır.

Anahtarın modu her şeyi belirler: test anahtarıyla açılan oturum `cs_test_…`, canlı anahtarla açılan `cs_live_…` olur ve oturum yanıtındaki `livemode` alanı buna göre gelir. Bir moddaki anahtar diğer modun oturumunu göremez (`404 checkout_session_not_found`).

## Test modunda neler farklı

| | Test | Canlı |
| --- | --- | --- |
| Aylık oturum kotası | Sayılmaz | Paketinize göre |
| `http://localhost` dönüş adresi | Kendiliğinden izinli | İzinli değil |
| `http://` izinli adres | Kabul edilir | Yalnızca `https://` |
| Ödeme | Yalnızca test kartları, gerçek para hareketi olmaz | Gerçek kartlar |
| Siparişler | **Test** olarak işaretlenir, Siparişler sayfasında **Test** filtresinde listelenir | **Canlı** filtresinde listelenir |
| Teslimat | Simüle edilir: oyun içi komut, stok, lisans ve rol işlemi yapılmaz | Gerçek teslimat |
| Bakiye, ödemeler, faturalar, vergi, ücretler, istatistikler | Etkilenmez | Dahil |
| Alıcıya giden e-postalar | Yalnızca makbuz, konu `[TEST]` ile başlar | Tüm sipariş e-postaları |
| Webhook'lar | `livemode: false` | `livemode: true` |
| İzinli adresler ve dönüş imza sırrı | Ayrı | Ayrı |

## Test kartları

Test oturumu aynı ödeme sayfasında test kart numaralarıyla ödenir; test modunda gerçek kartlar reddedilir. İleri bir son kullanma tarihi, herhangi bir üç haneli CVC ve herhangi bir posta kodu kullanın.

| Kart numarası | Sonuç |
| --- | --- |
| `4242 4242 4242 4242` | Ödeme başarılı |
| `4000 0025 0000 3155` | 3D Secure doğrulaması ister, ardından başarılı |
| `4000 0000 0000 9995` | Reddedilir (yetersiz bakiye) |
| `4000 0000 0000 0002` | Reddedilir (genel ret) |

<Note>
Test siparişleri bakiyenize ve ödemelerinize hiçbir zaman yansımaz, istatistiklerde görünmez. Teslimat simüle edildiği için oyun sunucunuzda komut çalışmaz. Ortamda test ödemeleri yapılandırılmamışsa test oturumunu ödemek `checkout_test_payments_unavailable` hatası verir.
</Note>

## Webhook işleyicinizi test etme

Test modundaki ödemeler mağaza uç noktalarınıza `livemode: false` ile gerçek webhook teslimatı gönderir; akışın tamamını uçtan uca deneyebilirsiniz. Mağaza uç noktaları iki modun olaylarını da alır: teslimat yapmadan önce `livemode` alanını kontrol edin.

İşleyicinizi ödeme yapmadan birim testiyle denemek için `@crafterpayments/node` ile geçerli bir imza başlığı üretin:

```ts
import { CrafterPayments, generateTestHeader } from '@crafterpayments/node';

const payload = JSON.stringify({
  event: 'checkout.completed',
  id: 'whd_test_1',
  version: '2026-12',
  createdAt: new Date().toISOString(),
  livemode: false,
  data: {},
});
const secret = 'whsec_test_...';
const header = generateTestHeader({ payload, secret });

const event = CrafterPayments.webhooks.constructEvent(payload, header, secret);
```

## Kodda modu anlama

- API yanıtlarında ve webhook gövdelerinde `livemode` test modunda `false` olur.
- `@crafterpayments/node` ile `crafter.livemode`, istemcinin anahtarının hangi modda olduğunu söyler.
- Test ve canlı anahtarlar ile oturumlar karıştırılamaz: canlı anahtar bir `cs_test_…` oturumunu okuyamaz.

## Canlıya geçiş

1. Paneli **Canlı** moda alın ve canlı bir gizli anahtar (`cp_sk_live_…`) oluşturun. Tarayıcıda canlı yayınlanabilir anahtarı (`cp_pk_live_…`) kullanın.
2. Canlı **izinli adresleri** kontrol edin: yalnızca `https://` web adresleri kabul edilir, `http://localhost` izinli değildir. Mağazanızın kendi alan adları kendiliğinden eklenir.
3. Canlı **dönüş imza sırrını** (`crs_…`) sunucunuza koyun; test modundakinden farklıdır.
4. Webhook işleyicinizin yalnızca `livemode: true` olaylarında teslimat yaptığından emin olun.
5. Paketinizin aylık canlı oturum kotasını ve istek sınırını [Paketler ve sınırlar](/tr/developers/payments/plans-and-limits) sayfasından kontrol edin.

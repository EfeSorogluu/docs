## 1. Genel Bakış

Crafter CMS temaları geliştirilip mağazada yayınlanarak binlerce mağazanın kullanımına sunulabilir. Geliştirme ve test süreçlerinin tamamı, bilgisayara ek bir kurulum gerektirmeden doğrudan `npx` üzerinden çalışan CLI aracı ile yönetilmektedir.

## 2. Şablon Motoru (Liquid)

Crafter CMS temaları tamamen **Liquid** mimarisi üzerine kuruludur:

- **Dinamik Veri Entegrasyonu:** HTML, CSS ve JS yapısı korunurken; Liquid etiketleri ile mağazanın dinamik verileri (ürünler, sepet, kullanıcılar vb.) anında sayfalara aktarılabilir.
- **Özellikler:** Güvenli, esnek ve yüksek performanslı bir yapı sunar.

### Örnek Kullanımlar

```liquid
<!-- Mağaza adını yazdırma -->
<h1>{{ shop.name }}</h1>

<!-- Varlık (asset) dosyasını çağırma -->
{{ 'style.css' | asset_url }}
```

## 3. Geliştirme Adımları

Sıfırdan bir tema projesine başlandığında CLI aracı, Liquid temelleriyle donatılmış hazır bir taslak altyapı (boilerplate) sağlar.

### 3.1. Platforma Giriş (Login)

Geliştirme işlemlerine başlamadan önce terminal üzerinden platformda oturum açılmalıdır:

```bash
npx @crafter-cms/cli@latest login
```

### 3.2. Tema Projesi Oluşturma (Init)

Yeni bir tema projesi başlatmak ve taslak Liquid dosyalarını oluşturmak için aşağıdaki komut çalıştırılır:

```bash
npx @crafter-cms/cli@latest init
```

### 3.3. Canlı Geliştirme Modu (Dev Mode)

Geliştirme esnasında yapılan değişiklikleri anlık olarak görüntüleyebilmek için proje klasörü dizinindeyken geliştirme modu başlatılır:

```bash
npx @crafter-cms/cli@latest dev
```

**Geliştirme Modunun İşlevleri:**

- Güvenlik dosyalarını (`crafter-manifest.json`) arka planda otomatik olarak üretir ve yönetir.
- Kodlar düzenlenip kaydedildikçe, değişiklikleri anında izole bir geliştirme (dev) ortamına senkronize eder.
- Liquid kodlarının doğrudan mağaza üzerinde anlık ve canlı olarak test edilmesini sağlar.

### 3.4. Sürüm Yayınlama (Publish)

Tema geliştirme süreci bittiğinde veya yeni bir güncelleme hazır olduğunda markete gönderim işlemi şu komutla yapılır:

```bash
npx @crafter-cms/cli@latest publish
```

**Yayınlama Adımında İstenen Bilgiler:**

1. **Sürüm Numarası:** Yeni versiyon tanımı (Örn: `1.0.0` veya `1.0.1`)
2. **Sürüm Notları:** Yapılan değişikliklerin kısa özeti

**Yayın Süreci İşleyişi:** Komut çalıştırıldıktan sonra CLI aracı, geliştirme ortamındaki kodları resmi bir paket haline dönüştürür ve markette yayınlanması amacıyla otomatik olarak onay sürecine iletir.

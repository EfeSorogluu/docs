Bu bölüm Crafter mağazaları için tema yazan ve oyun sunucusunu mağazaya bağlayan geliştiriciler içindir. Mağaza sahibi olarak tema kurmak ve düzenlemek için [Tema Kütüphanesi ve Düzenleyici](/tr/web-features/content/theme-library) sayfasına bakın.

<Note>
  Bu rehber **tema v2** (bölümler ve JSON şablonlar) ve **Crafter CLI 2.0.0** ve üstü içindir. Sürümünüzü `crafter --version` ile kontrol edin. v1 temalar (yalnızca `.liquid` şablonlu) değişmeden çalışmaya devam eder.
</Note>

## Hızlı başlangıç

```bash
npm install -g @crafter-cms/cli
crafter theme init benim-temam --v2
cd benim-temam
crafter theme check
crafter login
crafter theme dev --open
```

`crafter theme dev` temayı size özel, müşterilerin görmediği bir geliştirme temasına yükler ve `http://127.0.0.1:9292` adresinde mağazanın gerçek verisiyle önizler. Ayrıntılar [Crafter CLI](/tr/developers/themes/cli) sayfasında.

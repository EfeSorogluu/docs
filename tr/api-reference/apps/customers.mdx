Kapsam: `read_customers` (kişisel veri; manifestinizde gerekçesi olmalı, mağaza sahibine gösterilir). Müşteri kimliği `order.customer.id` alanından gelir. Başka mağazanın müşterisi `404 user_not_found` döner.

## Müşteri nesnesi

<ResponseField name="id" type="string" />
<ResponseField name="object" type="string">Her zaman `customer`</ResponseField>
<ResponseField name="livemode" type="boolean">Her zaman `true`</ResponseField>
<ResponseField name="username" type="string | null">Mağaza kullanıcı adı (çoğunlukla oyuncu adı)</ResponseField>
<ResponseField name="email" type="string | null" />
<ResponseField name="emailVerified" type="boolean" />
<ResponseField name="locale" type="string | null" />
<ResponseField name="createdAt" type="string | null">ISO 8601</ResponseField>

<ResponseExample>

```json 200
{
  "id": "CUSTOMER_ID",
  "object": "customer",
  "livemode": true,
  "username": "Steve",
  "email": "player@example.com",
  "emailVerified": true,
  "locale": "en",
  "createdAt": "2026-10-01T10:00:00.000Z"
}
```

</ResponseExample>

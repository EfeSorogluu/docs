Kapsamlar: listelemek için `webhooks:read`, oluşturmak ve silmek için `webhooks:write`. Yalnızca kurulumunuzun bu mağazada oluşturduğu uç noktaları görürsünüz. Bunlar **ek** uçlardır: Crafter'ın kurulumda uygulamanızın webhook adresi için oluşturduğu uç burada listelenmez ve panelden yönetilir ([uygulama webhook'ları](/tr/developers/apps/webhooks)). Olaylar, imza, yeniden denemeler ve olay kataloğu: [Webhook'lar](/tr/developers/payments/webhooks).

- `GET /v1/webhook_endpoints`: listeleme (kurulum başına en fazla 5, `hasMore` her zaman `false`).
- `POST /v1/webhook_endpoints`: oluşturma. `Idempotency-Key` zorunlu.
- `DELETE /v1/webhook_endpoints/{id}`: silme. Bekleyen gönderimleri durdurulur.

<ParamField body="url" type="string" required>Herkese açık `https://` adresi, en fazla 2000 karakter</ParamField>
<ParamField body="events" type="string[]" required>Katalogda uygulamalara açık, manifestinizde tanımlı ve token kapsamlarının karşıladığı olaylar (ör. `order.paid` için `read_orders` gerekir)</ParamField>
<ParamField body="livemode" type="boolean" required>`true`: yalnızca canlı olaylar, `false`: yalnızca test olayları</ParamField>
<ParamField body="description" type="string">En fazla 200 karakter</ParamField>

## Hatalar

| Tip | Durum | Ne zaman |
| --- | --- | --- |
| `app_webhook_events_invalid` | 400 | Bir olay bilinmiyor, uygulamalara açık değil ya da manifestte yok |
| `app_webhook_scope_missing` | 403 | Token kapsamları bir olayı karşılamıyor |
| `app_webhook_livemode_required` | 400 | `livemode` eksik |
| `app_webhook_limit_reached` | 400 | Zaten 5 uç nokta var |
| `store_webhook_url_invalid` | 400 | Herkese açık bir HTTPS adresi değil |
| `store_webhook_not_found` | 404 | Bu kurulumda böyle bir uç nokta yok |

<RequestExample>

```bash curl
curl https://api.crafterpayments.com/v1/webhook_endpoints \
  -H "Authorization: Bearer $CRAFTER_APP_TOKEN" \
  -H "Crafter-Version: 2026-12" \
  -H "Idempotency-Key: 6f1d0c1e-3b0a-4c55-9d1e-0a6c1f2b7a10" \
  -H "Content-Type: application/json" \
  -d '{ "url": "https://app.example.com/crafter/webhooks", "events": ["order.paid"], "livemode": true }'
```

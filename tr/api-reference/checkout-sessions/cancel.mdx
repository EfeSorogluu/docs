Gizli anahtar gerekir. Gövde gönderilmez.

- Açık oturum iptal edilir, ayrılmış kupon bırakılır ve `status` `canceled` olur.
- Zaten iptal edilmiş oturumda tekrar çağırmak hata vermez; oturum aynen döner.
- Tamamlanmış ya da süresi dolmuş oturum iptal edilemez: `409 checkout_session_not_open` (`details.status` güncel durumu verir).
- Ödeme işlenirken iptal edilemez: `409 checkout_payment_in_progress`. Sonucu webhook ile bekleyin.

<ParamField path="id" type="string" required>
  Oturum kimliği.
</ParamField>

<ParamField header="Authorization" type="string" required>
  `Bearer cp_sk_…`
</ParamField>

### Yanıt

`200 OK` ile [oturum nesnesi](/tr/api-reference/checkout-sessions/retrieve#oturum-nesnesi) döner.

<RequestExample>

```bash curl
curl -X POST https://api.crafterpayments.com/v1/checkout/sessions/cs_live_8fK2.../cancel \
  -H "Authorization: Bearer $CRAFTER_SECRET_KEY" \
  -H "Crafter-Version: 2026-12"
```

</RequestExample>

<ResponseExample>

</ResponseExample>

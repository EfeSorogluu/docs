**Bağlantı Adresi (Host):** Sunucu Sayısal IP Adresini Giriniz.

Bağlantı Portu: WebSender klasörün de config dosyasının için deki "socketPort" kısmında yazanı girin.

Şifre: WebSender klasörün de config dosyasının için deki "socketPassword" kısmın da yazanı girin.

---
title: "Server Vote Integrations"
description: "Reward players who vote for your server on popular gaming server lists."
---

Crafter connects with popular server listing sites and vote portals to automatically reward players with store credits, voting keys, or web chest items when they cast a vote.

---

## Supported Vote Directories

- **ServersMC**

---

## Configuration Workflow

<Steps>
  <Step title="Open Vote Settings">
    Navigate to [Dashboard \> Settings \> Vote](https://app.crafter.net.tr/en/dashboard/settings/vote).
  </Step>
  <Step title="Provide API Secret Keys">
    Enter your directory server token and API credentials.
  </Step>
  <Step title="Configure Voting Rewards">
    Specify the credit amount or in-game item rewards awarded upon voting.
  </Step>
</Steps>

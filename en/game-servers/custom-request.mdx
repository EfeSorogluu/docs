## Missing an Integration?

Looking for a game integration that isn't listed yet? Crafter is constantly expanding support for new multiplayer game engines and dedicated servers.

  Open a ticket on our Discord server to request bespoke game server integrations.
</Card>

---

## How to Submit a Request

1. **Join Discord:** [discord.crafter.net.tr](https://discord.crafter.net.tr)
2. **Open a Ticket:** Create a support inquiry in the designated channel.
3. **Share Specifications:**
   - Target game title and server platform (Steam, custom daemon).
   - Desired automation features (ranks, command execution, item delivery).
   - Any specific SDKs or modding frameworks used (Oxide, Lua, BepInEx).

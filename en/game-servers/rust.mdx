## Development Roadmap

<Info>
  **In Active Development:** Native CrafterConnect modules and webhook integrations for the listed games are rolling out sequentially. Complete walkthroughs and config templates will be released upon module launch.
</Info>

<Steps>
  <Step title="Phase 1: Core Protocols">
    Integrating RCON, Telnet, Webhook, and REST API command standards into the platform core.
  </Step>
  <Step title="Phase 2: Native Bridge Plugins & Scripts">
    Developing dedicated game engine plugins (Oxide, RocketMod, Lua, BepInEx, etc.).
  </Step>
  <Step title="Phase 3: Closed Beta & Documentation">
    Community server testing, automated store fulfillment validation, and publishing official documentation.
  </Step>
</Steps>

The only endpoint you can call from a browser or an app. It returns status fields only; buyer details, lines and metadata are not returned.

- Requires a publishable key (`cp_pk_…`). A secret key returns `403 api_key_wrong_type` here.
- `X-Client-Secret` must be the session's `clientSecret`; if it is wrong, `404 checkout_session_not_found`.
- If the request has an `Origin` header (a browser), that origin must be in the store's allowed origins; otherwise `403 checkout_origin_not_allowed`.
- CORS: `GET` only, no credentials (cookies). Allowed request headers are `Authorization`, `X-Client-Secret`, `Crafter-Version`; readable response headers are `X-Request-Id`, `Crafter-Version`.

<Warning>
This read is for showing the right message on screen. Confirm delivery and crediting items on your server, with the webhook or [Retrieve a session](/en/api-reference/checkout-sessions/retrieve).
</Warning>

<RequestExample>

```js Browser
const res = await fetch(
  `https://api.crafterpayments.com/v1/checkout/sessions/${sessionId}/public`,
  {
    headers: {
      Authorization: 'Bearer cp_pk_live_...',
      'X-Client-Secret': clientSecret,
      'Crafter-Version': '2026-12',
    },
  },
);
const status = await res.json();
```

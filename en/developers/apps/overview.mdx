An app adds features to Crafter stores. It runs on **your own server**, the store owner installs it from the app store, and it works with the store's data through the API, webhooks and an optional page inside the Crafter panel.

## How an app works

1. You create the app in the panel and get a **client id** and a **client secret**.
2. You publish a **version**: a [manifest](/en/developers/apps/manifest) (`crafter-app.json`) with the scopes and events the app needs, plus the store listing.
3. A store owner clicks **Install**. Crafter sends them to your **app URL**, your app starts [OAuth with PKCE](/en/developers/apps/oauth), the owner approves the scopes on the consent screen and your app gets tokens for that store.
4. Your app calls the [`/v1` API](/en/api-reference/apps/overview) with the access token, receives [webhooks](/en/developers/apps/webhooks) and can show an [embedded page](/en/developers/apps/embedded-pages) in the panel.
5. When the owner uninstalls the app, every token is revoked and your app receives `app.uninstalled`.

The token is always bound to one store, one app and the scopes the owner approved. You never pass a store id to the API.

## App kinds

| | Public | Private |
| --- | --- | --- |
| Who can install | Any store | Only the one store you choose when you create the app (you must own it) |
| Listed in the app store | Yes, after review | No |
| Review | Every version is reviewed by Crafter | No review: a submitted version is published at once |
| URLs | `https` only | `https`, or `http://localhost` while you develop |
| Consent screen | Normal | Shows that the app is not reviewed |
| Paid | Possible ([paid apps](/en/developers/apps/paid-apps)) | Not sold in the app store |

Start with a private app on your own store while you build, then create a public app when you are ready to list it.

## Available at launch

- OAuth 2.0 authorization code flow with PKCE, refresh token rotation.
- Read access to the store, products, categories, orders and customers, and the app's own webhook endpoints. See [scopes available at launch](/en/developers/apps/oauth#scopes).
- Webhooks: `order.*`, `checkout.*`, `app.installed`, `app.uninstalled`.
- One embedded page in the panel.
- Free apps, and one-time paid apps when paid apps open.

Write scopes (for example `write_products`) and game server commands are in the catalog but are not granted yet. A version that asks for them is refused.

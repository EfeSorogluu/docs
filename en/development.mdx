This section is for developers who build themes for Crafter stores and connect game servers to a store. To install and edit a theme as a store owner, see [Theme Library & Editor](/en/web-features/content/theme-library).

<Note>
  This guide covers **theme v2** (sections and JSON templates) and **Crafter CLI 2.x**. Check your version with `crafter --version`. v1 themes (with `.liquid` templates only) keep working unchanged.
</Note>

## Quick start

```bash
npm install -g @crafter-cms/cli
crafter theme init my-theme --v2
cd my-theme
crafter theme check
crafter login
crafter theme dev --open
```

`crafter theme dev` uploads the theme to a private development theme that customers never see and previews it with the store's real data at `http://127.0.0.1:9292`. See [Crafter CLI](/en/developers/themes/cli) for details.
